# Waylo — Trips That Fit You

A high-fidelity prototype for an AI-powered travel planning website.

## Prototype focus
- Scroll-driven travel-tech storytelling
- Three.js 3D globe with routes and travel points
- Waylo trip-planning flow
- Simulated AI itinerary generation
- Responsive design

## Run
This prototype is intentionally lightweight and can be opened as a static site. For local development, use any static server.

The current version uses Three.js from a CDN and remote travel imagery for the prototype experience.
